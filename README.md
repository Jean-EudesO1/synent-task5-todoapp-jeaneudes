# Application de liste de tâches

Projet réalisé dans le cadre du programme de stage en développement
web de Synent Technologies — Tâche 5.

## Présentation

Cette application permet d'organiser ses tâches quotidiennes.
Les tâches sont sauvegardées dans le navigateur avec localStorage.

## Fonctionnalités

- Ajouter une tâche.
- Refuser une tâche vide ou composée uniquement d'espaces.
- Marquer une tâche comme terminée ou à faire.
- Supprimer une tâche.
- Retrouver les tâches et leurs états après actualisation.
- Utiliser une interface adaptée aux mobiles.

## Technologies utilisées

- HTML
- CSS
- JavaScript
- localStorage

## Lancer le projet

1. Télécharger ou cloner le dépôt.
2. Ouvrir le dossier dans VS Code.
3. Ouvrir index.html avec l'extension Live Server.

Il est également possible d'ouvrir index.html directement dans
un navigateur. Pour les tests de sauvegarde, conserver le même
navigateur et la même adresse.

## Structure du projet

- index.html : structure de la page.
- style.css : apparence et adaptation aux petits écrans.
- script.js : gestion des tâches et sauvegarde locale.
- README.md : documentation du projet.

## Vérifier le fonctionnement

1. Ajouter deux tâches.
2. Marquer une tâche comme terminée.
3. Actualiser et vérifier que les tâches et leurs états sont conservés.
4. Supprimer une tâche.
5. Actualiser et vérifier qu'elle reste supprimée.

## Stockage

Les données sont enregistrées uniquement dans le navigateur utilisé.
Elles ne sont pas synchronisées entre appareils et peuvent être
supprimées si les données du site sont effacées.
